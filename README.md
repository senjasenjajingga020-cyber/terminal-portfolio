# Theodore's Terminal Portfolio

A simple terminal-style personal portfolio website built with HTML, CSS, and JavaScript.

## 🌐 Live Demo

[Open Theodore's Terminal Portfolio](https://senjasenjajingga020-cyber.github.io/terminal-portfolio/)

## ✨ Features

- Terminal-style interface
- Interactive commands
- Command history with `Arrow Up` and `Arrow Down`
- Tab autocomplete
- Neofetch-style system information
- Responsive design
- GitHub Pages deployment
